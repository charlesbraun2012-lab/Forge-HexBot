# Forge-HexBot
HexBot V2 is a mostly 3d printed 3d printer. The whole build cost is around $120, this was my second printer design and it taught me a lot about 3d printers. This  was sponsored by Wham Bam and LDO motors. This was also funded by the Forge YSWS on Hack Club. All the CAD is linked along with code and a build guide. If you choose to make this have fun!
